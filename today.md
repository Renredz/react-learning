## Three things I learned

1. React describes *what* the UI should look like, not *how* to update it.
2. JSX mixes HTML-like markup into JavaScript, and people hated it in 2013.
3. Hooks (2019) replaced class components.

**Question:** why did Facebook change the licence? License switched from BSD+Patents to MIT after community backlash; React 16. This unconventional clause caused some controversy and debate in the React user community, because it could be interpreted to empower Facebook to revoke the license in many scenarios

1. React apps are made out of components. A component is a piece of the UI (user interface) that has its own logic and appearance. 
A component can be as small as a button, or as large as an entire page.
React components are JavaScript functions that return markup

2. JSX lets you put markup into JavaScript. Curly braces let you “escape back” into JavaScript so that you can embed some variable from your code and display it to the user.
You can also “escape into JavaScript” from JSX attributes, but you have to use curly braces instead of quotes. 
In React, there is no special syntax for writing conditions. Instead, you’ll use the same techniques as you use when writing regular JavaScript code. 

3. When you build a user interface with React, you will first break it apart into pieces called components. Then, you will describe the different visual states for each of your components. Finally, you will connect your components together so that the data flows through them. In this tutorial, we’ll guide you through the thought process of building a searchable product data table with React.

4. React was made in 2011 by Jordan Walker at Facebook and in 2025 it moved to a new React Foundation under the Linux Foundation.
